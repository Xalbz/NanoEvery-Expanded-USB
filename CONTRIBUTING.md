# Contributing

Contributions are welcome, especially:

- reproduction tests on additional Nano Every boards
- keyboard/mouse live validation
- Linux/macOS build and flashing workflows
- reduction of SAMD11 flash usage
- USB descriptor/control-transfer review
- cleaner reproducible build automation
- protocol/library improvements on the ATmega4809 side

For hardware reports, include:

- Nano Every board revision if known
- OS and Arduino IDE/core version
- Expanded firmware SHA-256
- whether CDC, gamepad and normal `.ino` upload pass
- exact failure logs if something breaks

**Do not mark keyboard or mouse as verified until a real event test has been completed and documented.**

Do not post unique/private board backups unless you deliberately intend to publish them.
